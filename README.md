## 🔥 Why This Exists

GTA 6 launches on November 19, 2026. Preload starts November 12 — one week early. Rockstar has not announced an official file size, but the map is roughly twice the size of GTA 5, and estimates range from 150 to 200+ GB.

At the same time, the internet is flooded with fake "leaked builds." One 113 GB file was found to contain a 50 KB virus wrapped in empty code. The installer disabled Windows Defender and attempted to steal credentials. Another 130 GB file had a 0-byte installer and contained the Vidar infostealer.

This planner helps you prepare safely. No fake builds. No malware. No promises of a PC port that doesn't exist.

## 🧩 What It Does

### Storage Estimator
- Estimates space needed based on edition (Standard or Ultimate)
- Accounts for preload overhead and temporary files
- Shows range (low estimate / high estimate)

### Drive Space Check
- Scans all connected drives
- Shows available space versus estimated requirement
- Highlights drives that meet or fail the estimate

### Cleanup Guide
- Suggests large files and folders to remove or move
- Prioritizes by size and safe-to-delete status
- One-click open for Windows Storage Settings

### Fake Build Warning
- Built-in database of known fake GTA 6 file signatures
- Alerts if a scanned file matches a known fake
- Links to verified sources for official news

## ❓ FAQ

**Is this the game?**
No — it's a storage planner. GTA 6 is not available on PC. This tool helps console players prepare for the November 12 preload.

**Does this download any game files?**
No — the planner only reads your drive information and compares it against estimates.

**How accurate is the estimate?**
Rockstar hasn't announced an official size. The planner uses a range based on GTA 5, RDR2, and reported development build sizes. Actual size may differ.

**What are these fake builds?**
Files circulating online that claim to be leaked GTA 6 builds. Most contain malware — one 113 GB file had only 50 KB of actual code, the rest was empty padding. The planner warns if it detects known fake signatures.

**Will I get banned?**
This is a storage planning tool. It does not interact with any game or online service.

**How do I uninstall?**
Delete the planner folder. No registry entries or system changes are made.
